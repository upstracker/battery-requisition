# ระบบออกใบเบิกพัสดุและจัดการสต็อก (A5 Landscape Requisition System)

โปรแกรม Desktop Application สำหรับติดตั้งลง PC (Windows) พัฒนาด้วย **Python + CustomTkinter + SQLite** พร้อมระบบออกเอกสารใบเบิกขนาด **A5 แนวนอน** ภาษาไทยสวยงาม

---

## 🌟 จุดเด่นและฟังก์ชันการทำงาน

1. **ออกใบเบิกจ่ายแบตเตอรี่ขึ้นรถ (A5 แนวนอน):**
   - รันเลขที่เอกสารอัตโนมัติ (เช่น `REQ-202609-0001`) เลขที่ของใบที่ลบไปแล้วจะไม่ถูกนำกลับมาใช้ซ้ำ
   - หน้าจอแบ่งเป็น: แถบข้อมูลบิลด้านบน (เลขที่ วันที่ ลูกค้า ทะเบียนรถ บิลอ้างอิง; คนขับ/สายส่ง/หมายเหตุอยู่ใน "รายละเอียดการส่ง ▼")
     ซ้าย = ค้นหาและเลือกรุ่นแบต, ขวา = รายการในบิล, ล่าง = สรุปตรวจนับและปุ่มบันทึก
   - ไม่พบรุ่น? กดปุ่ม **"➕ เพิ่มแบตรุ่นใหม่"** เพื่อบันทึกรุ่นใหม่และเพิ่มลงบิลในขั้นตอนเดียว ส่วนอะไหล่ / สินค้าอื่นใช้ปุ่ม "📦 เพิ่มอะไหล่/สินค้าอื่น"
   - แต่ละรายการในบิลมีปุ่ม ⋯ สำหรับแก้ไขรายละเอียด/หมายเหตุ และเลื่อนลำดับ
   - แยก **หมวดสินค้า** ชัดเจน: หมวด "แบตเตอรี่" นับเป็นลูก ส่วนอะไหล่และสินค้าอื่นนับเป็นจำนวนรายการ
     (ยอดรวมบน PDF, หน้าประวัติ และ Excel แสดงเป็น `แบต 4 ลูก | อื่นๆ 1 รายการ`)
   - วันที่พิมพ์ได้ทั้ง `3/9/2026`, `03/09/2026` หรือปี พ.ศ. `3/9/2569` ระบบจะจัดเก็บเป็น `03/09/2026` (ค.ศ.)
   - สร้างไฟล์ PDF ขนาด A5 แนวนอน ภาษาไทยคมชัด และเปิดให้สั่งพิมพ์ได้ทันที
   - ถ้าบันทึกสำเร็จแต่สร้าง PDF ไม่ได้ (เช่น เปิดไฟล์ PDF เดิมค้างไว้) ระบบจะแจ้งให้ไปกดพิมพ์ซ้ำในหน้าประวัติ
   - **ไม่มีระบบตัดสต็อก** ใบเบิกใช้สำหรับจัดของขึ้นรถและตรวจเทียบกับบิลเท่านั้น
2. **ข้อมูลรุ่นแบตเตอรี่:**
   - เพิ่ม / แก้ไข / ลบ รุ่นแบตเตอรี่ ค้นหาตามยี่ห้อ รหัสรุ่น หรือขนาด Ah
   - เครื่องใหม่จะนำเข้ารุ่นจากไฟล์ `รุ่นแบตเตอรี่.xlsx` ให้อัตโนมัติตอนเปิดโปรแกรมครั้งแรก
3. **ประวัติและพิมพ์ซ้ำ (History):**
   - ค้นหาประวัติใบเบิกย้อนหลังตามช่วงวันที่ ลูกค้า เลขที่ คนขับ หรือทะเบียนรถ
   - ยอดสรุปและการส่งออก Excel นับทุกใบที่ตรงเงื่อนไข (ตารางบนจอแสดง 500 ใบล่าสุด)
   - สั่งพิมพ์ซ้ำ (Re-print PDF), ยกเลิกใบเบิก, ลบใบเบิกถาวร และล้างใบที่ยกเลิกทั้งหมด
4. **ตั้งค่าระบบ (Settings):**
   - ปรับเปลี่ยนชื่อบริษัท / องค์กร ที่จะแสดงบนหัวเอกสาร
   - ปรับชื่อหัวเอกสาร
   - กำหนดชื่อบทบาทผู้ลงนาม 3 ช่อง (เช่น ผู้ขอเบิก / ผู้อนุมัติ / ผู้จ่ายพัสดุ)

## ⚡ การคีย์แบตเตอรี่แบบเร็ว

- กด `F2` เพื่อไปยังช่องคีย์ด่วนจากทุกจุดในหน้าใบเบิก
- พิมพ์รุ่นหรือ `รุ่น*จำนวน` แล้วกด Enter เช่น `Q100*2`
  - เจอรุ่นเดียว หรือรหัสตรงทุกตัวอักษรเพียงรุ่นเดียว → เพิ่มลงใบเบิกทันที
  - เจอหลายรุ่นที่ใกล้เคียง หรือรหัสเดียวกันมีหลายยี่ห้อ (เช่น `N100`) → เปิดหน้าต่างให้เลือกรุ่นที่ถูกต้องก่อน
  - เลือกแถวในตารางเอง (ลูกศร ▲/▼ หรือคลิกแถว) แล้วกด Enter หรือดับเบิลคลิกแถว → เพิ่มแถวที่เลือก
  - กฎนี้ใช้เหมือนกันทั้ง Enter ในช่องค้นหา ช่องจำนวน และช่องหมายเหตุ
  - ไม่พบรุ่นในระบบ → เปิดหน้าต่าง "เพิ่มแบตเตอรี่รุ่นใหม่" โดยกรอกยี่ห้อ/รุ่น/จำนวนจากที่พิมพ์ไว้ให้
    (ถ้าไม่ใช่แบต กดปุ่ม "ไม่ใช่แบต → เพิ่มเป็นอะไหล่/สินค้าอื่น" ในหน้าต่างนั้นได้เลย)
- ใช้ช่องว่างแทน `*` ได้ เช่น `FB N100 4`
- การค้นหาไม่สนตัวพิมพ์เล็ก/ใหญ่ ช่องว่าง หรือขีด เช่น `55d-23l*4`
- ถ้ารหัสเดียวกันมีหลายยี่ห้อ ให้ใส่ยี่ห้อหน้ารุ่นเพื่อป้องกันเลือกผิด เช่น `FB N100*2`
- กด `Esc` เพื่อล้างคำค้นหาอย่างรวดเร็ว

## 🌐 ใช้งานหลายเครื่องในวงแลนด์

เลือก 1 เครื่องเป็น "เครื่องหลัก" (เก็บฐานข้อมูล) เครื่องอื่นเป็น "เครื่องลูก" ใช้ข้อมูลชุดเดียวกัน
เปิดโปรแกรมครั้งแรกจะมีหน้าต่างให้เลือก (เปลี่ยนภายหลังได้ที่ ⚙️ ตั้งค่า)
- เครื่องหลักรันเซิร์ฟเวอร์เบื้องหลัง (`python main.py --server`) และเปิดเองตอนล็อกอิน Windows
- เครื่องลูกค้นหาเครื่องหลักอัตโนมัติ หรือกรอก IP และรหัสเชื่อมต่อ 6 หลัก
- เลขที่ใบเบิกไม่ซ้ำแม้บันทึกพร้อมกัน และเตือนเมื่อสองเครื่องแก้ใบเดียวกัน
- รายละเอียดการตั้งค่าและรายการทดสอบอยู่ใน [HOW_TO_BUILD_WINDOWS.md](HOW_TO_BUILD_WINDOWS.md)

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

### 1. ติดตั้งไลบรารีที่จำเป็น
```bash
pip install -r requirements.txt
```

### 2. รันโปรแกรม
```bash
python main.py
```

### 3. รันชุดทดสอบ
```bash
python -m unittest discover -s tests
```

### ตำแหน่งเก็บข้อมูล
- รันจากซอร์สโค้ด: เก็บในโฟลเดอร์โปรเจกต์ (`data/inventory.db`, `output_pdfs/`, `database_backups/`, `exported_reports/`, `config.json`)
- ติดตั้งเป็น .exe บน Windows: เก็บที่ `%LOCALAPPDATA%\BatteryRequisition\` (ดู `HOW_TO_BUILD_WINDOWS.md`)
- ก่อนอัปเกรดโครงสร้างฐานข้อมูล ระบบจะสำรองไฟล์ไว้ใน `database_backups/` ให้อัตโนมัติ
